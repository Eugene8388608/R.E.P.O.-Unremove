# Unremove

<details>
<summary>Русский 🇷🇺</summary>
Мод для R.E.P.O., который добавляет в магазин предметы, отключенные разработчиками игры.

Этот мод не содержит текстур, моделей, префабов или других ресурсов; он нужен только хосту.

Отключенные предметы REPO v0.4.4:
* Healer Drone
* Recharge Orb
* Feather Orb
* Healer Orb
* Indestructible Orb
* Magnet Orb
* Roll Orb
</details>
