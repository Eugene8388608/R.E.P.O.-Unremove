# Unremove

<details>
<summary>Русский 🇷🇺</summary>
Мод для R.E.P.O., который возвращает предметы, отключенные или забытые разработчиками игры.

Этот мод не содержит текстур, моделей, префабов или других ресурсов; он нужен только хосту *для большинства предметов*.

Единственная отключенная ценность: мраморный столик в поместье лысого.

Отключенные покупные предметы R.E.P.O. v0.4.4:
* Лечебный дрон
* Сфера перезарядки
* Перьевая сфера
* Лечебная сфера
* Сфера защиты
* Магнитная сфера
* Сфера вращения
* Одна рация, которая сопряжена сама с собой

А также коробка улучшения броска. Её нужно включать отдельно в конфиге мода. По умолчанию коробка отключена, потому что хотя игроки без этого мода и будут её видеть, но взаимодействовать с ней нормально не смогут. **Необходим перезапуск игры после изменения этой опции**

<details open>
<summary>English 🇺🇸</summary>
R.E.P.O. mod that restores items, which are disabled or forgotten by game developers.

This mod contains no textures, models, prefabs or other resources. Only host needs it *for most items*.

A single disabled valuable: Manor Marble Table.

R.E.P.O. v0.4.4 disabled shop items:
* Healer Drone
* Recharge Orb
* Feather Orb
* Healer Orb
* Indestructible Orb
* Magnet Orb
* Roll Orb
* A single Walkie Talkie, which is paired to itself

And Throw Upgrade box. It should be enabled separately in mod config. It is disabled by default because although other players will see the upgrade box, they won't be able to interact with it properly. **Game restart is required after changing this option**
