# Unremove

<details>
<summary>Русский 🇷🇺</summary>
Мод для R.E.P.O. v0.4.4, который возвращает предметы и комнаты, отключенные или забытые разработчиками игры.

Этот мод не содержит текстур, моделей, префабов или других ресурсов; он нужен только хосту *для большинства игровых объектов*.

> **Необходим перезапуск игры после изменения настроек мода!**

Комнаты:
* Музей - Галерея в подвале
* Музей - Мелкие комнаты и лестницы

Комнаты, доступные только через [консоль отладки](https://repomods.com/apis/repolib/api/commands.html)
* Музей - Комната Моники (нет ценностей)
* Поместье - Обеденный зал 2 (замурованные ценности, пропадают стены)

Комнаты, доступные после включения в конфиге мода:
* Поместье - Стартовая комната с телевизором (нет точки сдачи)

Ценности:
* Поместье - Мраморный столик

Покупные предметы:
* Лечебный дрон
* Сфера перезарядки
* Перьевая сфера
* Лечебная сфера
* Сфера защиты
* Магнитная сфера
* Сфера вращения
* Одна рация, которая сопряжена сама с собой

Покупные предметы, доступные после включения в конфиге мода:
* Коробка улучшения броска (игроки без этого мода её видят, но взаимодействовать с ней не могут)

## Благодарности

<details open>
<summary>English 🇺🇸</summary>
R.E.P.O. v0.4.4 mod that restores rooms, shop items and one valuable, which are disabled or forgotten by game developers.

This mod contains no textures, models, prefabs or other resources. Only host needs it *for most game objects*.

> **Game restart is required after changing mod's config!**

Rooms:
* Museum - N - 2 - Basement Gallery
* Museum - N - 2 - Smaller rooms and stairs wip

Rooms available only through [debug console](https://repomods.com/apis/repolib/api/commands.html):
* Museum - N - 1 - Monika's Room (no valuables)
* Manor - N - 2 - Dining Hall 2 (walls are missing sometimes, obstructed valuables)

Rooms available after changing mod's config:
* Start Room - Manor - TV Room (no extraction point)

Valuables:
* Manor Marble Table

Shop items:
* Healer Drone
* Recharge Orb
* Feather Orb
* Healer Orb
* Indestructible Orb
* Magnet Orb
* Roll Orb
* A single Walkie Talkie, which is paired to itself

Shop items available after changing mod's config:
* Throw Upgrade box (players without this mod see the upgrade box, but they can't interact with it)
