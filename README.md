# Unremove

<details>
<summary>Русский 🇷🇺</summary>

Мод для R.E.P.O. v0.5.1, который возвращает предметы, комнаты и одного монстра, отключенные, недоделанные или забытые разработчиками игры.

Этот мод не содержит текстур, моделей, префабов или других ресурсов; он нужен только хосту *для большинства игровых объектов*.

> **Необходим перезапуск игры после изменения настроек мода!**

Через [консоль отладки](https://repomods.com/apis/repolib/api/commands.html) можно загрузить отдельные комнаты, в том числе комнаты для отладки. На данный момент в игре есть баг, из-за которого ванильные комнаты для отладки не загружаются. Мод предоставляет исправление, которое можно отключить в конфиге мода в случае каких-либо проблем.

Комнаты:
* Музей - Галерея в подвале
* Музей - Мелкие комнаты и лестницы
* Арктика - Грузовой центр
* Арктика - Сектор Эс
* Арктика - Обледеневший медблок

<details open>
<summary>English 🇺🇸</summary>

R.E.P.O. v0.5.1 mod that restores rooms, shop items, one valuable and one enemy, which are disabled, unfinished or forgotten by game developers.

This mod contains no textures, models, prefabs or other resources. Only host needs it *for most game objects*.

> **Game restart is required after changing mod's config!**

[Debug console](https://repomods.com/apis/repolib/api/commands.html) allows loading specific modules (rooms), including debug modules. Right now the game has a bug preventing loading vanilla debug modules. This mod provides a fix that can be disabled in mod's config.

Rooms:
* Museum - N - 2 - Basement Gallery
* Museum - N - 2 - Smaller rooms and stairs wip
* Arctic - M - 1 - Cargo Central
* Arctic - N - 3 - Sector S
* Arctic - P - 2 - Frozen Medbay
