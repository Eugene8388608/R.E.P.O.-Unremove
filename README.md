# Unremove

<details>
<summary>Русский 🇷🇺</summary>
Мод для R.E.P.O., который добавляет в магазин предметы, отключенные разработчиками игры.

Этот мод не содержит текстур, моделей, префабов или других ресурсов; он нужен только хосту *для большинства предметов*.

Отключенные предметы R.E.P.O. v0.4.4:
* Лечебный дрон
* Сфера перезарядки
* Перьевая сфера
* Лечебная сфера
* Сфера защиты
* Магнитная сфера
* Сфера вращения

А также коробка улучшения броска. Её нужно включать отдельно в конфиге мода. По умолчанию коробка отключена, потому что хотя игроки без этого мода и будут её видеть, но взаимодействовать с ней нормально не смогут. **Необходим перезапуск игры после изменения этой опции**
</details>

<details open>
<summary>English 🇺🇸</summary>
R.E.P.O. mod adding shop items that game developers have disabled.

This mod contains no textures, models, prefabs or other resources. Only host needs it *for most items*.

R.E.P.O. v0.4.4 disabled items:
* Healer Drone
* Recharge Orb
* Feather Orb
* Healer Orb
* Indestructible Orb
* Magnet Orb
* Roll Orb

And Throw Upgrade box. It should be enabled separately in mod config. It is disabled by default because although other players will see the upgrade, they won't be able to interact with it properly. **Game restart is required after changing this option**
</details>
